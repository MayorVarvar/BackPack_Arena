# Backpack Arena — техническое задание (рабочая версия 1.1)

Основа: «TZ_Backpack_Brawl_Minecraft_RU.pdf» v1.0 и справочник `Backpack_Brawl_Minecraft_Баланс.xlsx`.
Режим — оригинальный автобаттлер с инвентарём‑рюкзаком для Minecraft Java (Paper 1.21.x).
Жанр и механики (сетка‑рюкзак, магазин, крафт соседством, автобой) общие для жанра;
герои, предметы, названия и числа — собственные, задаются в YAML без правки кода.

## 1. Игровой цикл

```
выбор героя → магазин (покупка/продажа/реролл/резерв) → размещение в рюкзаке
→ автобой → крафт после боя → награды и доход → следующий раунд
```

Матч заканчивается, когда игрок набирает `wins-to-finish` побед (по умолчанию 10)
или теряет все жизни (по умолчанию 4). Ничья — без изменения жизней и побед.

Режимы MVP: **тренировка против бота** и **дуэль 1 на 1** (оба игрока готовятся
одновременно, бой начинается, когда оба нажали «В бой»).

## 2. Герои (`heroes.yml`)

| Герой | Архетип (из ТЗ v1.0) | Способность | Стартовые статы |
|---|---|---|---|
| Бастион | танк: броня, блок, шипы | «Железная стойка» — каждые 12 с +броня, 4 с отражение 50% поглощённого бронёй урона | HP 60, броня 15 |
| Эльма | стихии: огонь/лёд, мана | «Смена стихий» — каждые 6 с меняет огонь↔лёд; удары оружием накладывают Ожог или Холод | HP 50, мана 20 |
| Бортник | рой: питомцы, яд | «Улей» — каждые 10 с 2 пчелы на 6 с; пчёлы кусают и отравляют | HP 50 |
| Сильва | охотница: лук, крит, природа | «Лесной залп» — каждые 8 с 3 стрелы, урон растёт от числа дальнобойных предметов | HP 45, крит 10% |

Общие требования: индивидуальные HP, броня, выносливость, мана, крит; минимум одна
способность; общие и уникальные предметы (`hero:` в items.yml); всё настраивается.

## 3. Предметы (`items.yml`)

Поля: `id`, `name`, `description`, `rarity`, `category`, `material` (иконка),
`shape` (строки из `X`/`.`), `price`, `rotatable`, `hero`, `weapon` (урон, КД,
выносливость, точность, крит, ranged/pet), `effects` (триггер → действие).

Категории: WEAPON, ARMOR, POTION, FOOD, PET, MAGIC, MATERIAL, ACCESSORY, BAG.
Редкость (6 уровней): COMMON, RARE, EPIC, LEGENDARY, MYTHIC, UNIQUE.

Триггеры: `START`, `TIMER`, `ON_HIT`, `ON_CRIT`, `ON_ATTACKED`.
Действия: `ARMOR`, `THORNS`, `HEAL`, `BURN`, `POISON`, `CHILL`, `STUN`, `HASTE`,
`EMPOWER`, `LIFESTEAL`, `MANA`, `BLOCK`, `DAMAGE`.

## 4. Рюкзак и размещение

* Поле 6×9 (= двойной сундук). Сначала сумки (BAG) на пустые клетки, потом предметы
  только на клетки сумок. Пересечения запрещены, поворот на 90° для `rotatable`.
* Временное хранилище — основной инвентарь игрока (27 ячеек) на время матча;
  инвентарь игрока сохраняется и возвращается после матча.
* Сумку можно убрать только пустой.

## 5. Крафт (`recipes.yml`)

Рецепт — список ингредиентов, которые должны образовывать связную группу
(соседство по стороне). Проверка после боя; компоненты удаляются, результат ставится
на место компонентов или в хранилище. Блокировка (Shift+клик) исключает предмет из
крафта. Готовые рецепты подсвечиваются (зачарованное свечение). Ускоренный крафт
в магазине — за золото, цена растёт (`craft-hammer`).

## 6. Бой

Сервер полностью рассчитывает бой (детерминированно по seed), клиент только видит
повтор: босс‑бары HP, action bar, звуки, частицы, журнал в чат.

Тик 0,1 с. Порядок: реген выносливости/маны → статусы (раз в 1 с) → способности →
предметы с таймерами → атаки (точность → крит → блок → броня → HP → шипы/вампиризм)
→ проверка победы. Анти‑затягивание: с `fatigue-start` с обе стороны получают
растущий урон. Эффекты не вызывают цепочки триггеров (защита от бесконечных активаций).

Без выносливости оружие не бьёт, КД перезапускается. Питомцы не тратят выносливость.
Шипы срабатывают только на ближний бой. 1 броня поглощает 1 урон.

## 7. Магазин и экономика (`economy.yml`)

5 предложений; реролл 1/1/1/1/1/2/…/3 золота (список в конфиге); продажа — 50% (вверх);
скидка — шанс `sale-chance`, −33%; резерв предложения (правый клик) сохраняет его при
реролле. Шансы редкости по раундам и доход по раундам — таблицы в конфиге.
Реликвия — выбор 1 из 3 в раунде `relic-round`.

Мета‑ресурсы: опыт (уровень аккаунта), самоцветы, карточки (улучшения — этап 2).
Награды выдаются один раз на матч (флаг `rewarded`), баланс не может уйти в минус.

## 8. Реликвии (`relics.yml`)

Пассивные модификаторы: `max-hp`, `start-armor`, `mana-regen`, `burn-bonus`,
`pet-damage`, `lifesteal`, `accuracy`, `crit`. Лимит — `max-relics`.

## 9. Архитектура плагина

```
dev.backpackarena
├─ core            чистая Java, без Bukkit — покрыта юнит‑тестами
│  ├─ model        Rarity, Shape, ItemDef, HeroDef, RelicDef, RecipeDef, EffectDef…
│  ├─ grid         BackpackGrid, PlacedPiece — сетка 6×9, сумки, поворот
│  ├─ crafting     CraftingEngine — поиск связных рецептов
│  ├─ economy      Shop, EconomyConfig — предложения, реролл, продажа, доход
│  ├─ combat       CombatSimulator, Fighter, CombatLog — автобой
│  ├─ run          RunState — состояние игрока в матче
│  ├─ bot          BotFactory — сборка соперника для тренировки
│  └─ content      ContentLoader, GameContent — загрузка YAML и валидация
└─ plugin          Paper‑слой
   ├─ BackpackArenaPlugin, command/ArenaCommand
   ├─ session      SessionManager, PlayerSession, InventorySnapshot
   ├─ match        MatchService, Match (Training/Duel), BattleReplayer
   ├─ gui          HeroMenu, ShopMenu, BackpackMenu, RelicMenu, ItemRenderer
   └─ storage      Database (SQLite): профили, история матчей, сборки
```

## 10. Этапы

1. **MVP (этот корпус):** выбор героя, рюкзак, магазин, автобой, бот, дуэль, реликвии,
   базовые рецепты, сохранение профиля.
2. Предметы и крафт: подсказки рецептов (белый/жёлтый/зелёный), улучшения 1–5.
3. Герои: модели/анимации, больше способностей.
4. Экономика: самоцветы, задания, достижения.
5. Сохраняемые сборки, уникальные предметы за ранги.
6. Тесты, баланс, рейтинг, турниры, PostgreSQL.

## 11. Критерии готовности MVP

- [x] выбор одного из 4 героев; у каждого уникальная способность
- [x] сетка 6×9; покупка и размещение предметов
- [x] 6 уровней редкости; базовые рецепты
- [x] автобой; HP, броня, урон, статусы
- [x] магазин и золото; базовые реликвии
- [x] завершение матча и награда; данные сохраняются (SQLite)
